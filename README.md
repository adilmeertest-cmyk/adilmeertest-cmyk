## 👋 About Me

I am a Software Quality Assurance (SQA) professional focused on helping teams deliver reliable, consistent, and user-friendly software. My QA work includes manual testing, web and mobile application testing, structured test documentation, retesting, regression checks, and concise defect reporting.

I am continuing to build my technical QA skills through practical learning in API testing, SQL validation, and test automation.

## 🎯 QA Focus

- Manual and functional testing
- Web and mobile application testing
- UI validation, regression testing, and retesting
- Test scenarios, test cases, and test execution
- Clear, reproducible bug reports and defect communication
- API testing with Postman
- Database validation with SQL / MySQL
- Browser and network inspection with Chrome DevTools
- Learning automation with Playwright and Python
